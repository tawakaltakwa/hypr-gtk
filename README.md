## Hyprland Config

Konfigurasi Hyprland dengan aplikasi pendukung GTK. Default layout workspace 1 menggunakan SCROLLING dan workspace 2 menggunakan DWINDLE/tiling.

## Aplikasi yang digunakan
- Hyprland
- kitty
- Waybar
- nautilus
- wmenu
- mako
- gtklock
- wofi
- polkit-gnome
- Arimo Nerd Font
- NeoSpleen Nerd Font
