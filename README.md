## Hyprland Config

Konfigurasi Hyprland dengan aplikasi pendukung GTK. Workspace 1 menggunakan scrolling dan workspace 2 menggunakan dwindle/tiling.

## Aplikasi yang digunakan
- Hyprland
- kitty
- Waybar
- nautilus
- wmenu
- mako
- gtklock
- wofi
- grimblast-git
- polkit-gnome
- Arimo Nerd Font
- NeoSpleen Nerd Font
- python-gobject
